## Architecture note (not obvious from the file list)

The browser never talks to FastAPI directly for auth/dashboard routes. Per `api-contract.md`
§0.1/§0.11, it only ever calls Next's own `/api/*` (same-origin, no CORS needed). The four
`app/api/auth/*/route.ts` files are thin proxies (`lib/backend-fetch.ts`) that forward the
request (and cookies, both directions) to FastAPI at `BACKEND_PUBLIC_URL`. Server Components
(`(dashboard)/layout.tsx`, `page.tsx`) skip the proxy and call FastAPI directly since they
already run server-side.

## Deviations / decisions made during build

- shadcn's CLI defaulted to a Tailwind-v4-style preset (`@base-ui/react`, bare `border-border`
  utilities via `@import "shadcn/tailwind.css"`) — re-initialized explicitly on Radix
  (`-b radix`), which is what `CLAUDE.md` §3 names as the underlying primitive. Since we're
  pinned to Tailwind v3 (also a locked-stack decision), added the classic v3 color-token
  mapping to `tailwind.config.ts` instead of upgrading Tailwind.
- Dropped the Geist font shadcn's "Nova" preset wanted — not exported from `next/font/google`
  in Next 14.2.35 (Geist ships via a separate `geist` package or a newer Next version). No
  font is a fine default for a hackathon MVP; revisit if brand wants one later.
- `shadcn` (the CLI) moved from `dependencies` to `devDependencies`; `tw-animate-css` removed
  entirely (unused once the v4 import was stripped).
- Rate-limit lockout on `verify-otp` is attempts-based, tied to the current OTP challenge
  (locks once `attempts >= OTP_MAX_ATTEMPTS`, clears when a fresh OTP is requested) rather than
  a standalone 15-minute phone-level lock — `api-contract.md` §1.2 describes "phone locked for
  15 min" but the schema has no field for a lock window independent of the challenge's own TTL
  (5 min). Flagging the mismatch rather than inventing a new column un-asked.
- `X-RateLimit-{Limit,Remaining,Reset}` headers (api-contract.md §0.6) are not implemented —
  P1's own done-means checklist only requires the 429 status, not the headers. Revisit when P4
  adds dashboard read routes, since the doc wants these on every response, not just auth.

## Bugs found during build (real ones, not style nits)

1. **`config_test.py`**: the kill-switch test asserted the error mentions `DEV_AUTO_SEED`, but
   `DEV_SMS_LOG_TO_STDOUT` defaults `True` too and sorts first in the check loop, so it fired
   first. Test now pins all four switches explicitly.
2. **`main.py`** used `@app.on_event("startup")`, deprecated by FastAPI in favor of the
   `lifespan` context-manager pattern — switched.
3. **mypy false positives** on `Settings()` ("missing named argument" for every required field)
   — pydantic-settings populates those from the environment at runtime, which vanilla mypy
   doesn't know. Fixed by enabling pydantic's own mypy plugin (`plugins = ["pydantic.mypy"]`),
   not by silencing the check.
4. **`twilio` has no type stubs** — added a scoped `ignore_missing_imports` override for
   `twilio.*`, not a blanket one.
5. **`httpx.ASGITransport` vs FastAPI's `__call__` type** — a known stub-shape mismatch between
   the two libraries (functionally fine at runtime, confirmed by the passing test); one
   annotated `type: ignore[arg-type]`.
6. **`web`'s container-to-container call to `backend` used `http://localhost:8000`**
   (inherited from the shared `.env`, correct for the *host* but wrong inside a container,
   where `localhost` means itself). This silently broke every proxied route. Fixed with an
   explicit `BACKEND_PUBLIC_URL=http://backend:8000` override in both compose files.
7. **`npm run build` failed inside Docker** — Next tries to statically analyze route handlers
   at build time, and the four `/api/auth/*` routes call a backend that doesn't exist during
   an isolated `docker build`. Fixed by marking them `export const dynamic = "force-dynamic"`
   — correct regardless of Docker, since session-dependent routes must never be statically
   cached.
8. **Anonymous `node_modules` Docker volume went stale** — it persists across container
   recreation, so after `radix-ui` was added to `package.json`, rebuilding + recreating the
   `web` container still ran against the *old* `node_modules` (missing the new package) until
   the container's volumes were explicitly removed (`rm -f -s -v web`). Documented as a gotcha
   in the README; this will recur for any future `package.json` change.
9. **No `.eslintrc.json` or `.prettierignore` ever existed** (a P0 gap, only caught now because
   P1 was the first phase to actually run `npm run lint`/`prettier --check`). Added both;
   `.prettierignore` was letting Prettier walk `.next/` build output.

## What to expect

- Visit `/` with no session → redirects to `/login`.
- Enter pilot phone `+923005551234` → backend log shows `DEV_OTP: phone=... otp=... expires_in=300s`.
- Enter the OTP → redirects to `/`, header shows "Aslam Textiles" + avatar "AT", body shows
  "Assalam-o-alaikum, Aslam" and "Abhi tak koi agent nahi."
- Wrong OTP → Roman Urdu error inline, no redirect.
- 4th `send-otp` within an hour → `429 RATE_LIMITED`.
- 5 wrong OTP attempts on one challenge → `429 RATE_LIMITED` regardless of the 6th guess.
- Logout (avatar dropdown) → clears cookie, `/me` then returns `401`.

## Known gaps

- The 15-minute phone-level OTP lockout described in `api-contract.md` §1.2 is implemented as
  an attempts-based lock on the current challenge instead (see Deviations above) — doc and
  code now disagree; flagging rather than silently picking one.
- Real Twilio SMS path (`DEV_SMS_LOG_TO_STDOUT=false`) is unexercised — only the stdout dev
  path has been run.
